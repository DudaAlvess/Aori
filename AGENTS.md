# Orientações do projeto Aori

## Local de trabalho e identidade

- Desenvolver dentro de `C:\a3\code`.
- Preservar os materiais originais em `C:\a3`, fora desta subpasta.
- Usar a arte aprovada existente. Copiar os assets necessários para a aplicação,
  preservando integralmente a logo, e registrar os arquivos usados no README.
- Todas as estadias fictícias do catálogo devem ficar em Santa Catarina,
  com opções de serra, litoral e campo. Fotos e valores continuam ilustrativos.
- O link “Ver disponibilidade” deve abrir a página completa da estadia em uma
  nova aba, com seleção de datas e resumo do período demonstrativo.

## Aprovação e GitHub

- Implementar e verificar cada conjunto de mudanças localmente e apresentar
  o resultado ao usuário para revisão.
- Aguardar a aprovação do usuário antes de enviar esse conjunto de mudanças
  ao GitHub. Não interpretar silêncio como aprovação.
- Após a aprovação, fazer commit e enviar as alterações aprovadas ao repositório
  definido para este projeto, sem solicitar novamente a mesma autorização.
- Não incluir mudanças posteriores ou alheias ao conjunto aprovado no envio.
- Informar o resultado do envio e o link do commit ou pull request, quando houver.
